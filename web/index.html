A trading agent with no server

Vane lives on-chain as a Solidity contract. The Somnia chain itself wakes it to trade DreamDEX event contracts, reclaim its escrow and redeem what it wins. There is no bot process, no cron and no keeper. Close this page and it keeps going.

How it works

Four moving parts

  1. A subscription is stored in chain state The owner registers a filter on DreamDEX market events with the reactivity precompile at 0x0100, naming the agent as the handler.
  2. The chain calls the agent When a matching log lands, the node invokes onEvent on the contract. Nothing off-chain is involved, and there is nothing to keep running.
  3. It trades inside a policy it cannot exceed A per-window budget, a reserve it will never spend, a cooldown, and an allowlist of pools. Everything is checked on-chain before an order goes out.
  4. It gets the money back Expired orders hold escrow until something cancels them, and winnings must be claimed. A scheduled one-shot wake does both, and either can be triggered by anyone so funds are never stranded.
